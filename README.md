# Haikong Lu — Personal Website

A bilingual, responsive research homepage for [Haikong Lu](https://github.com/Haikong-Lu1206), built as a dependency-free static site for GitHub Pages.

## Local preview

Run any static file server from this directory, for example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Updating placeholders

- Replace `assets/avatar-placeholder.svg` with a portrait and update the image path in `index.html`.
- Replace `assets/osworld-placeholder.svg` with an OSWorld V2 project image and update the image path in `index.html`.
- Keep images compressed for faster loading on GitHub Pages.

## Publishing

The repository name is already `Haikong-Lu1206.github.io`. Push the site to the `main` branch, then confirm **Settings → Pages → Deploy from a branch → main / root**. The site will be served at <https://haikong-lu1206.github.io/>.

The previous travel-planner site remains available in this repository's Git history.
